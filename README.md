Hello to the Repo of "Egg Jump"
The game is supposed to resemble Doodle Jump in a way, we have had the theme of Bounceback so we decided to do a doodle Jump game.

The game is controlled as follows:
Left Arrow: Left,
Right Arrow: Right,
Space Bar: Jump,

The game is still currently being built on.
The game was made in Hack Haven Vienna event and it took a lot of work.
Please do not pirate the game.
