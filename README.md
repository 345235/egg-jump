Hello to the Repo of "Egg Jump"
The game is supposed to resemble Doodle Jump in a way, we have had the theme of Bounceback so we decided to do a doodle Jump game.

The game is controlled as follows:
Left Arrow: Left
Right Arrow: Right
Space Bar: Jump

The game is centered around the Egg that is jumping on platforms until its at the end.
It has premium 100k graphics and needs 4 5090s to run.
This is a very very good game.
